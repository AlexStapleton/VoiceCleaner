# Phase 1.5 — Adaptive Drift Compensation — Implementation Plan

> **For agentic workers:** subagent-driven-development. Steps use checkbox syntax.

**Goal:** Hold Ring B occupancy at its setpoint over an 8-hour session by adaptively resampling the output stream, cancelling the measured ~26 ppm capture/render clock drift so the shallow production rings survive (blueprint §5.8).

**Architecture:** A slow PI control loop watches a low-pass-filtered Ring B occupancy and outputs a resampling ratio near 1.0 (clamped ±100 ppm). A variable-rate cubic-Hermite resampler in the relay thread converts the K688-clocked stream to match VB-Cable's clock: relay pops a 480-frame from Ring A → resamples by the current ratio → re-frames to 480 → pushes to Ring B. New telemetry: ratio (ppm), filtered occupancy. All DSP/control logic lives in `transport-core` (platform-agnostic, unit-tested).

**Measured baseline (from Phase 0, 1 h on this hardware):** drift = −26.2 ppm (render faster than capture), so Ring B drains ~2.6 frames/min uncompensated. Compensator target: hold occupancy flat at setpoint; expect the converged ratio to report ≈ +26 ppm.

**Tech Stack:** C++20, existing transport-core + phase0-app.

---

## Design notes (rationale)

- **Ratio semantics:** `ratio = output_samples / input_samples`. When Ring B occupancy < setpoint (draining), we must emit *more* output per input → ratio > 1. So `error = setpoint − filtered_occupancy` (positive when draining) drives ratio up. Measured drift drains Ring B, so the loop will settle at ratio ≈ 1 + 26e-6.
- **Slowness is the point (§5.8 step 4):** time constants of seconds-to-tens-of-seconds; small gains. We correct samples/minute, so reacting fast buys nothing and risks instability. Tiny per-frame ratio changes are inherently smooth (a step change would click; these are sub-ppm/frame).
- **Cubic Hermite (Catmull-Rom)** interpolation with a 3-sample carried history gives clean quality across frame boundaries; at ±100 ppm even linear would be inaudible, but Hermite is the right tool and not much harder.
- **Placement:** in the relay (the future DSP thread), after any processing, before Ring B — matching §5.8 "last thing in the chain, before Ring B's consumer."
- **A/B:** a `drift_compensation` config flag (default true). Off → exact Phase 0 behavior. This lets us prove the loop by comparing occupancy slope on/off.

## Task 1: `Resampler` — variable-rate cubic-Hermite

**Files:** Create `src/transport-core/resampler.h`, `resampler.cpp`; Test `tests/transport-core/test_resampler.cpp` (add to `tests/transport-core/CMakeLists.txt` sources).

Interface:
```cpp
// resampler.h
#pragma once
#include <cstddef>
namespace vc {
// Variable-rate resampler (ratio ~1.0). ratio = output_samples / input_samples.
// Maintains fractional read position + a small input history for continuity across calls.
// RT-safe: no allocation. Catmull-Rom cubic interpolation.
class Resampler {
public:
  void   set_ratio(double ratio) noexcept;   // clamps to a sane band internally is NOT done here
  double ratio() const noexcept;
  // Consume n_in input samples; write resampled output into out (capacity out_cap).
  // Returns number of output samples produced. Never writes past out_cap.
  size_t process(const float* in, size_t n_in, float* out, size_t out_cap) noexcept;
  void   reset() noexcept;
private:
  double ratio_ = 1.0;
  double pos_   = 0.0;      // fractional position in the *incoming* stream, relative to start of `in`
  float  h_[3]  = {0,0,0};  // last 3 samples of the previous input block (x[-3],x[-2],x[-1])
  bool   primed_ = false;
};
}
```
Implementation guidance:
- Effective input step per output sample = `1.0 / ratio_`.
- Build a virtual indexable stream: indices −3..−1 come from `h_`, indices 0..n_in−1 from `in`. Catmull-Rom at fractional position `p` uses samples at floor(p)−1, floor(p), floor(p)+1, floor(p)+2.
- Loop producing output while the cubic's needed max index (floor(pos)+2) is available within `in` (i.e. `floor(pos)+2 <= n_in-1`) and out count < out_cap; advance `pos_ += 1/ratio_` per output sample.
- After consuming the block, carry the last 3 input samples into `h_`, and subtract `n_in` from `pos_` so it stays relative to the next block's start. Set `primed_` after first block.
- Catmull-Rom: for t in [0,1], `y = 0.5*((2*p1) + (-p0+p2)*t + (2*p0-5*p1+4*p2-p3)*t^2 + (-p0+3*p1-3*p2+p3)*t^3)` where p0..p3 are consecutive samples.

## Task 2: `LeakyIntegrator` + `DriftController` (PI)

**Files:** Create `src/transport-core/drift_control.h`, `drift_control.cpp`; Test `tests/transport-core/test_drift_control.cpp` (add to test CMake).

```cpp
// drift_control.h
#pragma once
#include <cstddef>
namespace vc {
// One-pole low-pass (leaky integrator): y += alpha*(x - y). alpha from a time constant.
class LeakyIntegrator {
public:
  explicit LeakyIntegrator(double alpha) : a_(alpha) {}
  double update(double x) noexcept { y_ += a_ * (x - y_); return y_; }
  double value() const noexcept { return y_; }
  void   set(double v) noexcept { y_ = v; }
private:
  double a_; double y_ = 0.0;
};

// Slow PI loop: setpoint on Ring B occupancy -> resampling ratio near 1.0.
class DriftController {
public:
  struct Config { double setpoint; double kp; double ki; double maxPpm; double filterAlpha; };
  explicit DriftController(const Config& c);
  // Feed the current raw Ring B occupancy (frames). Returns the ratio to apply (output/input).
  double update(double occupancy) noexcept;
  double ratioPpm() const noexcept;     // (ratio-1)*1e6, for telemetry
  double filteredOccupancy() const noexcept;
private:
  Config cfg_; LeakyIntegrator lpf_; double integ_ = 0.0; double ratio_ = 1.0;
};
}
```
Implementation:
- `update`: `filt = lpf_.update(occupancy); err = cfg_.setpoint - filt; integ_ += err; ratio_ = 1.0 + cfg_.kp*err + cfg_.ki*integ_;` clamp `ratio_` to `[1 - maxPpm*1e-6, 1 + maxPpm*1e-6]`; anti-windup: if clamped, don't accumulate integ_ further past the clamp (clamp integ_ too). Return ratio_.
- Defaults (in the wiring task): setpoint = ringB.capacity()/2, maxPpm = 150, filterAlpha ≈ 0.02 (with ~100 Hz updates → ~0.5 s TC), kp and ki small (e.g. kp = 2e-7, ki = 2e-9) — tune so the loop settles over ~tens of seconds without oscillation. Gains are conservative; the wiring task exposes them in config.

## Task 3: Wire compensation into the Bridge + telemetry + config

**Files:** Modify `src/phase0-app/bridge.h/.cpp`, `src/transport-core/config.h/.cpp`, `src/phase0-app/logger.h/.cpp`, `src/phase0-app/main.cpp`.

- **Config additions** (`config.h/.cpp`): `bool driftCompensation = true;`, `double kp`, `double ki`, `double driftMaxPpm = 150.0;`, `double filterAlpha = 0.02;` with sane defaults (kp=2e-7, ki=2e-9). Parse from TOML (`drift_compensation`, `drift_kp`, `drift_ki`, `drift_max_ppm`, `drift_filter_alpha`); `validate()` leaves them (add bounds only if trivial). No CLI flags required beyond existing.
- **Bridge** (`bridge.h/.cpp`): add members `Resampler resampler_;`, `DriftController* controller_` (or by value, constructed in start() once setpoint = ringB_.capacity()/2 is known — construct in ctor from cfg with setpoint computed there), `FrameAccumulator reframe_;`, and a scratch `std::vector<float> rs_out_;` (reserve ~2*FRAME_SAMPLES).
  - **relayLoop change:** when `cfg_.driftCompensation` is true, for each frame popped from Ring A:
    1. `controller_.update(ringB_.size())` → `ratio`; `resampler_.set_ratio(ratio)`.
    2. `size_t m = resampler_.process(frame.data(), FRAME_SAMPLES, rs_out_.data(), rs_out_.capacity());`
    3. `reframe_.write(rs_out_.data(), m);` then `while (reframe_.pop_frame(f2.data())) if(!ringB_.try_push(f2)) dropouts_.record_overrun();`
    When false: keep the exact Phase 0 verbatim copy path.
  - Store latest `ratioPpm` and `filteredOccupancy` as atomics for telemetry.
- **Logger** (`logger.h/.cpp`): add two columns `ratio_ppm,filt_occ` to the CSV header + rows, and to the console line. The Logger needs read access to the bridge's atomics — pass a `const std::atomic<double>*` for each (or a small struct pointer). Keep RT-safe (relaxed atomics).
- **main.cpp:** no structural change; the config flag drives it.
